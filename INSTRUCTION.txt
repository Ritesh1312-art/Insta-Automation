📌 KAUN SI CHEEZ KAHA SE MILEGI? (KEYS & CREDENTIALS GUIDE)
-------------------------------------------------------------------------------

1. DATABASE_URL:
   - Kaha se milegi: Supabase (supabase.com) ya Neon (neon.tech)
   - Kaise milegi: Free account banayein -> "Create Project" -> Database Settings -> Connection String (URI) copy karein.
   - Format: postgresql://postgres:password@db.supabase.co:5432/postgres

2. META_APP_ID aur META_APP_SECRET:
   - Kaha se milegi: Meta Developer Portal (developers.facebook.com)
   - Kaise milegi: Log in -> My Apps -> Apne App par click karein -> App Settings -> Basic.
   - Top par App ID aur App Secret (Show button daban) dikh jayega.

3. META_VERIFY_TOKEN:
   - Kaha se milegi: Yeh aapki apni marzi ki koi bhi secret text/password ho sakti hai.
   - Example: `my_custom_webhook_verify_token_123`
   - Note: Jo string `.env` me rakhenge, wahi Meta Webhook setup karte waqt "Verify Token" box me type karni padegi.

4. AUTH_SECRET aur ENCRYPTION_KEY:
   - Kaha se milegi: Yeh aapki marzi ki koi bhi secure random 32-character string ho sakti hai (Pre-filled default string pehle se `.env.example` me added hai).

5. META_REDIRECT_URI:
   - Kaha se milegi: Vercel par deploy hone ke baad jo aapko live domain URL milega, uske aage `/api/auth/meta/callback` lagayein.
   - Example: `https://your-app-name.vercel.app/api/auth/meta/callback`

6. META_API_MOCK:
   - "true" = Local offline test karne ke liye (Bina real Meta tokens ke).
   - "false" = Live production me real Instagram DMs bhejne ke liye.
