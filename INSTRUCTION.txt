REAL META DEPLOYMENT CHECKLIST

1. Configure production environment variables from .env.example. Generate unique values for AUTH_SECRET, ENCRYPTION_KEY, CRON_SECRET, SETUP_TOKEN, and META_VERIFY_TOKEN.
2. Deploy the application at an HTTPS URL and set APP_URL and META_REDIRECT_URI to that URL.
3. In Meta Developers, add the OAuth redirect URI /api/auth/meta/callback and the webhook callback /api/webhooks/meta. Subscribe the instagram comments field.
4. Open /setup once, create the first administrator with SETUP_TOKEN, then keep the token private.
5. Sign in, connect the real Instagram professional account, sync content, add real resources, and create automations.
6. Use the configuration check before publishing an automation. It never sends a message; only incoming signed Meta comment webhooks can trigger delivery.
7. Confirm Vercel Cron is enabled. It invokes the protected retry worker every five minutes for transient Meta failures.
